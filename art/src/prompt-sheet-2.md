Second character pose sheet for the same 2D animated short. The FIRST reference image is our approved model sheet for the Monkey King: copy that exact drawing style, line weight, colours, proportions, face and costume. Same character, same artist. Do not redesign anything. The other references are older crude frames, only for costume details.

Style: identical to the first reference: clean hand-drawn 2D animation cel, confident dark brown-black ink outline with varying line weight, flat colour with one soft shadow tone. No gradients, no texture, no 3D look.

Layout: exactly 6 drawings in a 3 x 2 grid, each fully inside its own cell with wide empty space around it, nothing touching or crossing between cells. Background: one flat solid magenta (#FF00FF) everywhere, no floor, no ground shadows, no text, no labels, no grid lines. He holds NO staff and NO weapon; where a fist is closed it is empty.
